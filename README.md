# zebra-support

Support, privacy policy and landing page for **Zebra Music** — a playful iOS
music-theory trainer.

- **Live site:** https://zebra-musicapp.com (GitHub Pages, custom domain via `CNAME`)
- **App Store:** https://apps.apple.com/app/id6756319231
- **Contact:** zebra.music@outlook.fr

## Structure
- `index.html` — single-page site (hero, features, progression, privacy, support).
- `assets/` — brand artwork (`logo.png`, `app-icon.png`, `zebra-teacher.png`),
  copied from the app's `Assets.xcassets`.
- `CNAME` — custom domain mapping.

No build step: it's a static page served straight from `main`.
